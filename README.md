# Tesis: Análisis Comparativo de Arquitecturas CNN para Clasificación de Cáncer de Mama

**Autora:** Amira Jimena Roman Juchani
**Universidad:** Universidad Privada del Valle
**Carrera:** Ingeniería en Ciencia de Datos e Inteligencia de Negocios

## Descripción

Comparación de arquitecturas de redes neuronales convolucionales (ResNet-50, DenseNet-121, EfficientNet-B4) para la clasificación de cáncer de mama en mamografías digitales 2D, usando Multiple Instance Learning (MIL) con atención.

## Dataset

- **Principal:** CBIS-DDSM (mamografías 2D con confirmación por biopsia)
- **Validación externa (opcional):** INbreast, Mini-MIAS
- **Datos clínicos:** Hospital Univalle Zona Norte (Cochabamba, Bolivia)
